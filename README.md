# homebrew-diffier

Homebrew cask tap for [Diffier.app](https://github.com/afitzgerald/diffier), an IntelliJ-style
Git commit tool window + diff viewer for macOS.

```sh
brew install --cask afitzgerald/diffier/diffier
```

Casks are published automatically by diffier's release workflow — don't edit `Casks/` by hand.
